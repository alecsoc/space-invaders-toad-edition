# Space Invaders: TOAD Edition 🛸
Implementación del clásico arcade desarrollada en Python con Pygame y el Arcade Machine SDK. Este proyecto forma parte de la cátedra de Taller de Objetos y Abstracción de Datos (Grupo 8, sección Lunes).

## 📝 Descripción
Una reimplementación del icónico Space Invaders centrada en principios de ingeniería de software. El juego ha sido rediseñado desde cero para ser totalmente compatible con el ecosistema de la "Máquina Arcade" de la asignatura, priorizando la modularidad y el desacoplamiento de datos.
